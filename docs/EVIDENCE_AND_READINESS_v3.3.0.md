# Доказательства и готовность к запуску — PROTOCOL ZERO v3.3.0

## Подтверждение действий

Портал считает факты двух видов:

- **Sandbox:** событие пришло от тестовой площадки. Оно подтверждает работу интеграции, но не рекламный эффект и не сделку.
- **Live:** настроенный адаптер принял серверно подписанное сообщение `artifact_created` или `campaign_saved`. Это свидетельство заявления партнёра, а не независимое подтверждение продажи.

Только серверный Conversion Bridge может записать партнёрское событие в production API. Пользовательское нажатие в браузере или клиентское событие GA не подменяет этот механизм. Счётчики `sandbox` и `live` не суммируются в один «бизнес-успех».

A/B-цели из старой схемы сохраняются отдельно: исходная таблица не указывает окружение, поэтому из них нельзя вывести настоящую live-выручку без нового подписанного контракта и миграции.

## Проверки запуска

`GET /api/business-briefs/BRF-ID/launch-check` возвращает восемь булевых критериев, два явных отказа от подтверждения (`businessValidation`, `paymentIntegration`) и список проверок, которые надо проводить вне приложения.

`BLOCKED` — пока не выполнены все технологические критерии. `TECHNICAL_PILOT_CANDIDATE` — есть технические признаки для ограниченной проверки; **не является автоматическим разрешением на публичный запуск**.

Операторская команда:

```bash
npm run ops -- release-preflight
npm run ops -- doctor
npm run backup -- ./backups/before-release.sqlite
npm run ops -- team-prune
# Выполняйте только после подтверждённой резервной копии:
npm run ops -- team-prune --execute --backup-confirmed
```

При проверке не выводятся HMAC-ключи. Исходный файл `config/platforms.demo.json` содержит только локальный демонстрационный адаптер; реальных семи подключений нет.

## Настоящая производственная готовность дополнительно требует

Аутентификации юридических клиентов, секретов из менеджера ключей, обратного прокси HTTPS, восстановлений из резервных копий, мониторинга, политики персональных данных, ручной проверки рекламных прав и claims, независимой проверки реальных рекламных показателей, нагрузочных тестов и пилота с первым платящим клиентом. Ни один из этих шагов не объявлен выполненным в тестовой сборке.
