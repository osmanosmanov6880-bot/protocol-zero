# PROTOCOL ZERO — RELEASE 2.3.0 / SECOND FIVE WAVES

Основа: проверенная локальная версия 1.8.0. Исправления/новые возможности:

- **WAVE 06:** защищённые ссылки, токен которых показывается владельцу только при создании на клиентское согласование, выбранные immutable публичные snapshots, ограничения срока, revoke и блокировка после модерации.
- **WAVE 07:** отзывы гостей с регистрацией через cookie вместо профиля, рейтинг+комментарий, строгая защита владельца и других гостей, приватный decision register с аудиторскими записями.
- **WAVE 08:** отчёт по качеству A/B-назначений, долям показа, Wilson 95%, SRM/перекосу выборок; никакой автоматической рекомендации winner.
- **WAVE 09:** запрос на коммерческий пилот, операторский письменный оффер, статусы и подтверждение интереса самим владельцем; бухгалтерских/платёжных событий нет.
- **WAVE 10:** additive SQLite schema, privacy export/delete, rate-limit, отдельная CLI-очистка с dry-run, `doctor`, обновлённые smoke/CI/check, новая адаптивная UI-система.

**Обратная совместимость:** корневые кампании, новые ветви, приглашения, Conversion Bridge, рабочие копии, A/B-планы, аналитика и действующие интеграции не удаляются при повторном открытии базы.

**Достоверность:** ни один партнёр из семи сайтов не интегрирован по реальным API в этом релизе, платежи и выручка не подтверждены. Локальный демопартнёр остаётся демо. Скриншоты созданы браузером из реального интерфейса с API-тестовым мостом, **не нарисованные UX-макеты**.

**Проверка:** `npm run check`, `npm test`, `npm run smoke`, `npm run verify:release`, открытие нового архива в чистом каталоге, отдельная проверка миграции предыдущей SQLite. Публичное развёртывание остаётся отдельным действием оператора.
