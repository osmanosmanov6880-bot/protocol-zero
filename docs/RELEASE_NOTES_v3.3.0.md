# v3.3.0 — WAVE 16–20

**Дата:** 22 октября 2026 г.  
**База:** v2.8.0.  
**Статус:** локальная, проверяемая рабочая версия для продуктовых пилотов. Не заявлена production-готовность.

Новые модули `team-access.js`, `client-deliverables.js`, `partner-evidence.js`, `commercial-audit.js`, `launch-readiness.js` и единая схема `waves16-20-schema.js`.

Рабочие страницы `/delivery/BRF-ID`, `/team/join/TOKEN`, `/team/BRF-ID`. Основной кабинет `/command/BRF-ID` сохранил прежние разделы и получил переход к новым возможностям.

Выполнены ограничения доступа и контента: hashed one-time invitations, ограничения ролей, отзыв, неизменяемые HTML/JSON-подборки, экранирование HTML, SHA-256-контроль, разделение sandbox/live в доказательствах, явный список блокирующих критериев запуска.

**Тесты:** 80/80 тестов Node.js, проверка отдельного Chromium-сценария с двумя независимыми браузерными сессиями и разрешениями 390/768/1440, миграция настоящей старой базы v2.8.0, резервное копирование. Для Chromium использован тестовый HTTP-мост, поскольку прямую браузерную навигацию на локальный адрес блокирует среда; это не end-to-end тест на внешнем домене.

**Не интегрированы:** семь реальных сайтов, реальные банки/платежи, SSO/MFA, живой сервер и независимое измерение оплаченных рекламных кампаний.
