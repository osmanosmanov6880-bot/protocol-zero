# PROTOCOL ZERO v2.8.0 — WAVE 11–15

## Принцип релиза

Все пять блоков внедрены в прежнее веб-приложение на Node.js / SQLite. Исполняемые файлы находятся в `src/`, интерфейс — в `public/`, тесты — в `tests/waves11-15.test.js`. Публичная история мутаций неизменяема. Никаких внешних API, реальных транзакций или доказанной эффективности рекламы в этом релизе нет.

## WAVE 11 — Управление живой кампанией

- `campaign_controls`: состояние `open | paused`, причина и автор изменения.
- `campaign_control_log`: неизменяемый след переходов состояний.
- Редактор брифа управляет состоянием через `PUT /api/business-briefs/:id/control` с `{ "status":"paused", "reason":"..." }` (для возобновления `open`).
- Сервер запрещает новые изменения и приглашения, если кампания приостановлена; исторические публичные страницы остаются читаемы.
- Оператор может восстановить состояние через отдельный **локальный CLI** `campaign-pause` / `campaign-resume` при потере браузерной сессии владельца. Это аварийный обход, не публичная веб-функция.
- Тесты: посторонний пользователь не меняет кампанию; повторный переход даёт 409; история сохраняется.

## WAVE 12 — Неизменяемые пакеты рекламных вариантов

- `creative_packs`: JSON-фотография кампании, 1–8 выбранных публичных потомков, SHA-256.
- Назначения: `internal`, `client_review`, `experiment`.
- Не разрешены чужие ветви, исходный корень или скрытый модерацией контент. Нет доступа для постороннего браузера.
- Лимит 30 сохранённых пакетов на кампанию и ограничение частоты создания. Клиент может скачать JSON через интерфейс.
- При просмотре хеш пересчитывается; если содержимое испорчено, возвращается ошибка `PACK_TAMPERED`.
- Это локальный контроль целостности, не внешняя криптографическая аттестация и не подтверждение рекламной эффективности.

## WAVE 13 — Необратимое завершение A/B-эксперимента

- `experiment_closures`: причина остановки, сохранённый снимок расчётов проверки качества, SHA-256, время.
- Транзакция закрытия приостанавливает план и сохраняет отчёт. Повторное закрытие запрещено.
- Любые новые распределения, показы и цели отклоняются после закрытия, включая события, формально подписанные подключённым партнёром.
- В сохранённом отчёте — **описательные данные** и известные ограничения. Нельзя трактовать его как независимую оценку продаж или доказательство причинного эффекта.

## WAVE 14 — Операционные этапы пилотов

- `pilot_milestones` + `pilot_milestone_log`.
- Оператор создаёт этап, только если коммерческий пилот перешёл в статус `accepted`. Затем предъявляет результат на ознакомление.
- Заказчик выбирает `acknowledged` или `changes_requested`, указывает причину. Оператор может вновь представить исправленный результат.
- Не более 12 этапов на пилот. История смены статуса сохраняется.
- **Важно:** даже `acknowledged` подтверждает только событие ознакомления в приложении, не банковский платёж и не акт юридической приёмки.

## WAVE 15 — Центр управления бизнесом

- `/command/BRF-ID` (либо кнопка «Центр бизнеса» в кабинете «Для бизнеса»).
- Единое окно реальных количественных показателей: открытые видимые потомки, уникальные анонимные браузеры-авторы, пакеты, клиентские комнаты, отзывы, A/B-планы, закрытые тесты, запросы на пилоты и их этапы.
- Текущая блокировка/открытость кампании, редактируемые панельные операции, экспорт пакетов и отчёта эксперимента.
- Личные материалы доступны только автору одобренного брифа; никаких публичных методов управления владельцами/операторами.
- Метрики не обозначены доходом, количеством людей, успешными продажами или доказанной рекламной прибылью.

## Совместимость, проверка и безопасность

- Миграция `migrateWaves1115` содержит аддитивные `CREATE TABLE IF NOT EXISTS`; прежние таблицы и данные не удаляются.
- При обновлении обязательно сохранить секрет анонимной сессии. Иначе прежний владелец сможет потерять доступ к своим частным материалам.
- `npm run check`, `npm test`, `npm run smoke`, `npm run verify:release` должны проходить **после чистой распаковки готового ZIP**.
- Браузерные проверки интерфейса проводились на 390/768/1440 px через локальный HTTP API и тестовый мост из-за запрета прямой loopback-навигации в Chromium. Это не эквивалент тестирования публичной инфраструктуры.
- Не выполнены: подключение семи действующих рекламных систем, реальный платёжный эквайринг, проверка спроса реальными клиентами, production security review, юридическая проверка для публичного запуска.
