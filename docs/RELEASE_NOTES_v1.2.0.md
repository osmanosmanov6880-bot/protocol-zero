# PROTOCOL ZERO / Наследники v1.2.0 — Release Notes

**Статус:** запускаемый локальный технический MVP. Внешние рекламные сервисы пользователя и платежи не подключены. Создана тестовая партнёрская интеграция как два независимых HTTP-сервера.

## Реализовано

1. Реестр из 0–7 адаптеров с режимами `sandbox` и `live`, проверкой адресов, названий и безопасности, секреты только из environment.
2. Новый экран «Рекламный мост», история передачи брифов, статусы и отзыв.
3. Согласие на отправку и явный выбор источника: публичная версия или приватная рабочая копия.
4. Backend `handoffs` с собственными идентификаторами, зафиксированными snapshot, сроком действия 30 дней, записью открытия и получения.
5. Новый server-to-server протокол: HMAC(time + raw body), ±300 секунд, разные секреты партнёров, проверка отправителя, идемпотентность результата.
6. Второй самостоятельный локальный редактор, который сохраняет собственный демо-макет в собственной SQLite, получает бриф только после редиректа и посылает подписанный webhook.
7. Статистическое разделение sandbox и live. Никаких выдуманных оплат или конверсий.
8. Раздельные структурированные JSON-брифы; авторские заметки никогда не передаются при `source=public`.
9. Операторская воронка и CSV (только агрегаты), команды управления передачами.
10. Автоматические проверки совместимости версий 1.0/1.1 и end-to-end API тесты 1.2.

## Как проверить

```
node --version
npm run check
npm test
npm run demo
```

`http://127.0.0.1:8787` — PROTOCOL ZERO; `http://127.0.0.1:8790` — второй сервер демо-партнёра. У обоих собственная SQLite. Для локального обычного запуска только портала: `npm start`.

**Дизайн QA:** HTML/CSS/JS визуально отрендерен в desktop и mobile в Chromium. В этой среде прямая браузерная навигация на loopback-адреса заблокирована, поэтому браузер обращался к фактическим HTTP-ответам API через тестовый мост. Это доказывает работу интерфейсной логики, но **не** production-сетевой путь браузера.

## Известные ограничения

- Ни одна из семи реальных площадок пользователя пока не изучена и не подключена.
- В тестовой мастерской нет настоящей рекламы, клиентов, оплаченных заказов или бизнес-метрик.
- Демо-бренды и краткие брифы вымышлены.
- Экспортируемые брифы требуют проверки законности и фактов до использования в рекламе.
- Нет распределённого хранения, аккаунтов для разных устройств, SMTP, платежей или SSO.
- До публичного запуска необходимы HTTPS, production-конфиг, anti-bot, privacy review и реальный оператор.
