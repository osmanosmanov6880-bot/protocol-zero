# PROTOCOL ZERO v1.8.0 — 5 WAVE release notes

Дата: 22 октября 2026. Предыдущий выпуск: v1.3.0.

## Реализовано

1. **Creative Safety:** автоматические предупреждения о неподтверждённых числах, гарантиях и срочности в заголовках/CTA; запрет вставлять контакты в публичные мутации. Сервис проверки текста — не доказательство законности и не измерение эффективности.
2. **Business Curation:** приватный редакционный отбор публичных вариантов, заметки владельца и экспорт, скрывающий приватные данные и модерированные ветви.
3. **A/B Laboratory:** зафиксированные A/B креативы, метрика, гипотеза, собственный JSON kit, серверные назначения и подписанные partner impression/goal с защитой от повторов; draft без реального подключённого рекламного сайта не создаёт показатели.
4. **Insight Studio:** графики количества мутаций, типов изменений, приглашений и браузерных участников; без придуманных пользователей, выручки, продаж или causal lift.
5. **Operator & Security:** аддитивная миграция, last_seen сессий, readiness, явная безопасная очистка старых данных по dry-run, операционные команды, CI, smoke-тест.

## Изменённые маршруты

- `/lab/:briefId` — владелец кампании, экспериментальная лаборатория.
- `/insights/:briefId` — владелец кампании, статистика участия.
- `/api/preflight`, `/api/branches/:id/preflight`.
- `/api/business-briefs/:id/reviews`, `/api/business-briefs/:id/insights`, `/api/business-briefs/:id/experiments`.
- `/api/experiments/:id`, `/api/experiments/:id/kit`, `/api/experiments/:id/activate`, `/api/experiments/:id/pause`.
- `/api/integrations/v2/experiment-assign`, `/api/integrations/v2/experiment-event` (HMAC, live backend only).
- `/api/ready`.

## Проверки выпуска

- Node.js 22.16: **44/44** автоматических теста.
- `npm run check` — успешно; `npm run smoke` — успешно.
- Браузерная проверка новых страниц 1440, 768 и 390px через изолированный тестовый мост к настоящему HTTP API; горизонтального overflow и ошибок JS в этих сценариях не наблюдалось.
- Сценарий в двух анонимных сеансах: частный бриф -> ручная публикация -> дочерняя мутация -> кабинет владельца -> A/B план -> аналитика.
- Миграция с SQLite версии 1.3 проверена отдельно: старые записи сохраняются.
- После сборки: распаковать архив, повторить `npm run check`, `npm test`, `npm run smoke`, `npm run verify:release`, сравнить SHA-256.

## Известные границы

0/7 реальных сторонних рекламных платформ подключено; нет production-трафика и достоверных рекламных результатов; платежей и подписок нет. A/B endpoints принимают только подписанные события сервера партнёра; доверие к самому партнёру и его соблюдение согласованного определения конверсии требуется проверять отдельно. Не представлен промышленный observability, юридическая проверка реального GDPR-сценария, нагрузочный аудит и внешняя проверка безопасности. Sandbox-результаты не равны коммерческим.

## Обновление

Остановите старый процесс, сделайте backup `data/` и секретов, распакуйте новую версию в новую директорию, перенесите старые `data/` и затем запустите. Не переносите SQLite одновременно между работающими серверами. Локальная миграция добавляет новые таблицы и поле `last_seen_at`, не удаляя существующие ветви. Обязательно сначала тест на копии настоящей базы.
