# Отчёт по качеству / PROTOCOL ZERO 1.2.0

## Зафиксировано

- Node.js 22.16.0 (исходники требуют 22.13+).
- `npm run check`: синтаксическая проверка `server.js`, `database.js`, `bridge.js`, `analytics.js`, `ops.js`, `backup.js`, `public/app.js`, демонстрационных серверов — завершена успешно.
- `npm test`: **19 пройдено / 0 не пройдено**.
- API E2E: два независимых анонимных браузера по HTTP, однократные приглашения, родословная, изоляция приватного рабочего черновика, модерация, безопасность Open Graph/социальных карточек, миграции 1.0/1.1.
- Conversion Bridge: разрешённый переход владельца, недопущение чужого доступа, signed resolve, signed confirm, проверка времени и подписи, идемпотентный повтор, конфликт ID, различение demo vs live, отзыв, скрытые публикации, privacy delete.
- **Отдельный smoke test:** `npm run demo` поднимает порт 8787 и 8790; тестовая мутация отправлена, второй сервер сохранил демо-объект в отдельную SQLite, подписанный callback принят; `sandboxActions >= 1` и `partnerLiveActions = 0`.
- `npm run ops -- funnel`: построена первая локальная воронка, без личных данных.
- `node src/backup.js` создал резервную копию SQLite и проверил целостность.

## Визуальная проверка

Оригинальные HTML, CSS и JavaScript были отрисованы в Chromium в 1440px и 390px. Проверены главная, изменение гена, результат, окно согласия, кабинет платформ и тестовый партнёр. JS ошибок при этих проходах: **0**. Горизонтального переполнения для кабинета и партнёра при 390px: **нет**.

**Ограничение среды:** прямой `page.goto(http://127.0.0.1:8787)` и даже навигация по синтетическому адресу блокируются политикой `ERR_BLOCKED_BY_ADMINISTRATOR`. Поэтому для визуальной проверки использован тестовый браузерный мост: фактические HTTP-ответы API проходят через Python requests в `window.fetch` оригинального JS; статичные HTML/CSS/JS — исходные. Это UI-проверка с реальным backend, **не** production-проверка сетевого стека Chromium. Настоящий независимый HTTP E2E из двух Node-процессов проверен отдельно.

## Исключено из утверждений

- Никакие из семи реальных рекламных сайтов пользователя не подключены.
- Не проверены публичный HTTPS-домен, продакшн-шлюз, нагрузка, резервное восстановление на другом сервере или распределённое масштабирование.
- Нет пользователей/оплат, кроме тестовых сессий в QA; показатели QA **не** представляют спрос.
- Нет реальной генерации коммерческой рекламы: демонстрационный партнёр сохраняет учебные объекты.
- Скриншоты — результаты реального рендера интерфейса в тестовой среде, не фотогенерация.
