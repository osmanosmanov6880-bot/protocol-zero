# RELEASE NOTES — v2.8.0 (PROTOCOL ZERO / WAVE 11–15)

## Включено

- Управление паузой/возобновлением одобренной кампании с операторским восстановлением и аудитом.
- Закрытые неизменяемые коллекции публичных рекламных версий, контроль SHA-256 и запрет выдачи скрытого контента.
- Необратимая фиксация A/B-экспериментов с блокировкой последующих даже корректно подписанных событий партнёра.
- Этапы выполнения коммерческих пилотов: `planned → submitted → acknowledged` или `changes_requested → submitted`.
- Центр бизнеса `/command/:briefId`: состояние кампании, пакеты, планы, пилоты, фактические счётчики.
- Новые таблицы без разрушения предыдущих данных. Обновлён CLI, API, тесты и документация.

## QA

- 55 сохранённых тестов прошлых волн + 11 новых = **66/66** автоматических тестов.
- Серверный smoke (включая новый SPA маршрут `/command/...`).
- Chromium UI test bridge к настоящему API: новая бизнес-заявка → ручная публикация → изменение чужой сессией → пакет → пауза → закрытый A/B; 390/768/1440 px без горизонтального переполнения и консольных ошибок в проверенных экранах.
- Новый release ZIP должен быть повторно распакован и проверен по SHA-256 в новом каталоге.

## Известные ограничения

- Пока нет интеграций с семью внешними рекламными сайтами; демонстрационный партнёр остаётся только sandbox.
- Успешность A/B проверок зависит от корректности событий настоящей внешней площадки. Локальная HMAC-подпись не заменяет независимую сверку продаж.
- Установка рассчитана на локальный одиночный Node.js процесс и SQLite; перед публичным запуском нужны production deployment, HTTPS, безопасность, юридическая проверка и масштабирование.
- Клиентские согласования и этапы пилотов не заменяют подписанный договор, платёж или юридическую приёмку.
