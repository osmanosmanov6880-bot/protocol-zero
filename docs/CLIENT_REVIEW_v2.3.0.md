# Закрытые согласования: пользовательский маршрут и безопасность

## Рекламодатель

1. Публикует коммерческую кампанию после ручной операторской проверки в разделе «Для бизнеса».
2. Открывает **«Отзывы клиентов»**; выбирает 1–6 публичных вариантов, срок ссылки 1/7/30 дней.
3. Нажимает **«Создать закрытую ссылку»** и копирует ссылку сразу: сервер хранит только SHA-256 токена.
4. Передаёт ссылку конкретным тестировщикам. Ссылка является capability: **любой обладатель ссылки** может просматривать варианты и оставлять комментарий; это НЕ проверка личности приглашённого.
5. Смотрит приватные отзывы и помечает `new`, `considered` или `rejected`, добавляет приватную заметку. Может закрыть доступ раньше срока.

## Клиент

1. Открывает `/review/<token>` без регистрации.
2. Читает выбранные и зафиксированные рекламные варианты, выбирает оценку 1–5, оставляет письменное пояснение.
3. Видит собственные ответы, но не ответы других людей.
4. Чтобы удалить свой комментарий и cookie-сессию, открывает страницу конфиденциальности в том же браузере и удаляет данные. Удаление не стирает саму публичную кампанию.

## Модель угроз и её пределы

- URL токена содержит около 256 бит случайности. База хранит SHA-256 (`pz-review-v1:` + token); SQL dump не раскрывает само право доступа.
- Срок и отзыв проверяются **на сервере** при каждом запросе; сессия владельца необходима для управления комнатой.
- Все ответы JSON `Cache-Control: no-store`; закрытые страницы отдают `X-Robots-Tag: noindex,nofollow,noarchive` и глобальный `Referrer-Policy: no-referrer`.
- Чужие private workspace/notes, email, ID браузеров и другие отзывы гостю не доступны.
- Комментарии имеют длину, валидацию и лимиты. Это базовая защита от злоупотреблений, не продвинутый anti-spam.
- Для строго юридического B2B-согласования нужна аутентификация клиента, идентификация ответственного лица, подтверждение электронной подписи, отдельное соглашение и защищённый аудит. Этот MVP — **дизайн-ревью**, не сервис юридических согласований.
- Ссылка является секретом — не помещайте её в публичные публикации и стороннюю аналитику. Отозвать ссылку после пересылки можно, но пользователь мог сохранить вручную прочитанные данные.
