# PROTOCOL ZERO · CINEMATIC INTERACTIVE ENGINE v1.0.0

**«Наследники сигнала»** — интерактивный браузерный научно-фантастический фильм с 15 режиссёрскими сценами, двумя маршрутами через архив, изменяемым рекламным геномом и двумя принципиально разными концовками. В том же движке предусмотрен автономный трёхсценный прототип с выбором роли. Основной интерфейс русский, переключение EN и 中文 в настройках.

## Открыть сразу

Самый простой способ — двойной щелчок по **`VIEW_OFFLINE.html`**. Это полностью автономная версия со встроенными WebP, CSS и JS. Если браузер ограничит `file://`-хранилище, кино всё равно будет работать, но сохранение прогресса между сеансами может быть недоступно.

Рекомендуемый способ для полноценного хранения прогресса:

1. Установить Node.js 22.13+ (никаких `npm install` не требуется).
2. Windows: `START_WINDOWS.cmd`; Linux/Mac: `./START_UNIX.sh` или `npm start`.
3. Открыть **http://127.0.0.1:8080**.
4. Прототип из трёх сцен: **http://127.0.0.1:8080/prototype/**.
5. `npm test` — проверка графа и логики; `npm run check` — проверка синтаксиса + тесты.

## Как смотреть

Выбирайте действия, ищите светящиеся архивные фрагменты на фоне, используйте «Назад», чтобы переиграть развилку. Откройте «Архив», чтобы вернуться в уже посещённую сцену. На девятом эпизоде вы узнаете рекламный геном; на десятом разрешено написать свою версию одного поля (HOOK/TONE/CTA). Остальные поля не редактируются.

В двух финалах можно скачать **настоящий локальный JSON-бриф**. Для перехода в рекламную платформу ссылка задаётся отдельно в `story/site-config.mjs`. Фильм не публикует данные на сервере, не регистрирует пользователей и не создаёт платежей.

## Техническая архитектура

- HTML5, CSS, нативные ES Modules, SVG, Canvas (легковесные частицы), WebAudio (только после нажатия).
- `story/scenes.mjs` — содержание и переходы 15 сцен; `story/prototype.mjs` — трёхсценная история.
- `story/engine.mjs` — детерминированные переходы, история, фрагменты, локальный экспорт, валидация графа.
- `src/app.mjs` — интерфейс и визуальная последовательность; `src/audio.mjs`, `src/particles.mjs` — процедурные эффекты.
- `assets/keyframes` — 9 групп фонов в 2 адаптивных размерах, WebP.
- `docs/` — концепция, visual bible, таблица 15 кадров, 15 промптов, звук, интерактивность, производственные ограничения и QA.
- `previews/` — настоящие браузерные снимки. `tools/make_browser_preview.py` — только тестовый bridge; рабочая браузерная версия не нуждается в Python.

## Автоматическое сохранение

Прогресс и настройки хранятся только в `localStorage` текущего браузера (отдельные ключи фильма и прототипа). На сервер ничего не уходит. Сброс — настройки/архив → «Начать заново». Альтернативные сцены доступны для исследования, а локальная история восстанавливается при нажатии «Назад».

## Качество и честные ограничения

Кадры имеют WebP 1600×900/720×1080, но **исходные изображения — фрагменты двух композитных концептов, увеличенные при обработке; это не натуральная 4K/8K-детализация**. Переходы, параллакс, туман/частицы — программные. Персонажи и события вымышлены. Цифры продаж/эффективности рекламы не генерируются и не показаны.

`docs/ASSET_MANIFEST.md` и `assets/ASSET_MANIFEST.json` перечисляют исходники. Для коммерческого визуального релиза рекомендовано заменить 9 основных артов по точным заданиям в `docs/SHOT_PROMPTS.md` — код менять не требуется.

## Связь с платформой PROTOCOL ZERO v3.3.0

В файле `story/site-config.mjs` задан **локальный адрес** `http://127.0.0.1:8787`. Он откроется только в случае отдельного запущенного приложения v3.3.0. Межсистемное сохранение данных и серверная интеграция в кинодвижок не включены; не используйте фильм как свидетельство «реальных оплат». `SITE.productUrl` можно заменить после проверки вашего домена.
