# PROTOCOL ZERO CINEMA ENGINE v1.0.0

## Включено

- 15 сцен в полном режиссёрском графе, 2 основных пути через мир, 3 интерактивных гена, 2 финала.
- 3-сценный прототип с выбором Создателя/Наблюдателя и локальным изменением финала.
- Детерминированный story engine, история переходов с проверками, недоступность закрытых сцен, архив, 8 интерактивных архивных подсказок.
- Реальный редактор одного рекламного элемента, текстовый diff в следующей сцене, локальный JSON-export.
- Русский/английский/китайский UI, мобильная адаптация, режимы качества и доступности, субтитры, звук с явным включением.
- Независимая HTML-версия со встроенными картинками; модульный JS без сторонних зависимостей.
- Оригинальные процедурные звуки, адаптивные WebP, CSS-камера, Canvas-частицы.
- Полная спецификация: концепция, visual bible, storyboard, граф, 15 production prompts, audio, export, QA, deployment.

## Не входит

- Нативные 4K/8K ключевые кадры, настоящее кинопроизводство/озвучка, автономная AI-режиссура.
- Публичная публикация, домен и интеграция с API рекламных сайтов.
- Серверное сохранение пользовательской версии, платежи, аккаунты или реальные A/B-показатели.

## Проверено

Node.js: 19/19 тестов, включая статический HTTP-сервер и граф обеих историй. Chromium: статический адаптивный UI 1440/390, основные переходы в обеих историях, полный desktop-сценарий, комментарии к экранному состоянию и экспорт JSON в изолированном browser bridge. Полную production-навигацию по реальному HTTPS необходимо проверить после публикации.
