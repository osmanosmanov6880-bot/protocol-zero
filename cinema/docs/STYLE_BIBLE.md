# Визуальная библия: «Архив после света»

**Ключевой образ:** заброшенный небесный город и глубокий архив из окисленного металла, тёмного стекла, камня и янтарных линий питания. Не неоновый клуб, не интерфейс обычного SaaS и не набор одинаковых синих сцен.

| Система | Спецификация |
|---|---|
| Палитра | `#070C12` obsidian, `#0E1E27` deep petroleum, `#DDE3DC` chalk, `#B5DCCB` mint-cyan signal, `#E1AD73` brass amber, `#DA786A` corrosion red |
| Свет | Горизонтальный закат города / холодная боковая лампа архива / контровой янтарь лаборатории / тишина и серо-белый свет финала |
| Материалы | Матовый титан, патинированная бронза, мокрый гранит, рифлёное стекло, вытертый архивный картон, микропыль |
| Оптика | Широкий 28–35 mm на архитектуре; средний 50 mm на Эдде; крупный 75–85 mm на артефактах; мягкая периферийная дымка |
| Глубина | Передняя тёмная арка, средний светящийся объект, дальний светящийся город. Для фотографии без масок — очень умеренный pan/zoom кадра |
| Персонаж Эдда | Женщина около 45–55, короткие тёмные волосы с серебристой прядью, чёрная архивная форма с бронзовым треугольным знаком. В MVP — силуэт/одна опорная фотография, без генерации несогласованных лиц |
| Графический мотив | Разомкнутое кольцо «0» с тонкой диагональной линией; три стебля генома; нумерация инцидентов; архивная черта |
| Типографика | Системный geometrical grotesk (`Inter` если установлен, fallback Segoe UI/Arial); моноширинный системный для метаданных. Основные титры от 36 до 84 px адаптивно |
| Интерфейс | Содержимое на отдельной затемнённой поверхности в безопасной зоне слева; фон не конкурирует с текстом; читабельные вторичные подписи |
| Анимация | Редкий 18–26-секундный dolly, микропараллакс, плавное исчезновение света, 180–400 ms UI-переходы; `prefers-reduced-motion` подавляет движение |
| Звук | Очень тихий синтезированный drone, сигналы выбора и редкая пауза; старт звука только по клику |

## Запреты

- Не размещать текст внутри исходных изображений: все сюжетные титры в HTML.
- Не выдавать рендеры из маленького кропа за нативные 4K/8K.
- Не использовать агрессивные хроматические аберрации, постоянный шум экрана, strobe и бесконечную панораму.
- Не создавать фальшивые цифры пользователей, конверсий, продаж или недоказанные рекламные обещания.
- Не блокировать движение дальше невидимыми pixel-hunts: находки факультативны.
- Не требовать звука/мыши/быстрой реакции для прохождения.
