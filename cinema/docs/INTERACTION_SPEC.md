# Интерактивность: контракт поведения

Вся логика сцен — в `story/engine.mjs`, данные — в `story/scenes.mjs` и `story/prototype.mjs`.

## Последовательность

- `createState(mode)` — только стартовый кадр и пустой путь.
- `advance(state,choiceId,text)` — проверяет существующую кнопку данной сцены, применяет переход и его эффект, записывает предыдущий снимок.
- `back(state)` — восстанавливает прошлый снимок вместе с тогдашними решениями. Открытые сцены и найденные фрагменты остаются доступны в архиве.
- `jump(state,id)` — доступен только для посещённой сцены; восстанавливает её исторический контекст, а не просто меняет заголовок.
- `discover(state,id)` — добавляет только существующий hotspot текущей сцены; повторное нажатие не множит находки.
- `restoreState` — игнорирует повреждённую/чужую версию сохранения. Ключ хранения для полного фильма и прототипа различный.
- `exportGenome` — создаёт **локальный** JSON, не отправляя данные на рекламный сервер.

## Ветки

- `threshold`: посетитель выбирает `worlds` → `seven` или `proof` → `corridor`; каждый путь приводит к `edda` и далее.
- `seven`: можно посмотреть `corridor` или пропустить расследование и перейти к `edda`.
- `mutation`: одна операция над `HOOK`, `TONE` или `CTA`; пользователь может ввести свой текст (3–140 символов), остальные продуктовые характеристики защищены.
- `verdict`: `open` → тёплый финал / `seal` → сдержанный финал.
- Прототип: `proto_start` → `proto_choice` → `proto_final`; последний кадр показывает разные следы для `creator` и `observer`.

## Чего экран НЕ делает

1. Не сохраняет пользователя на удалённом сервере.
2. Не добавляет вариант рекламы в базу PROTOCOL ZERO v3.3.0.
3. Не создаёт платёж, регистрации, конверсии или A/B-показателя.
4. Не экспортирует чужие данные — фильм использует только локально введённые слова.

## Экранные элементы

- Выбор: полноценный HTML `button`, допускает Enter/Space и стрелку вправо для первой опции.
- Назад: кнопка и ArrowLeft/Backspace (когда фокус не в редакторе).
- Находка: позиционированная кнопка с текстовой подписью и modal/dialog, работает без наведения мыши.
- Архив: modal/dialog с кнопками ранее открытых кадров.
- Настройки: язык RU/EN/ZH; качество auto/cinematic/balanced/lite; reduced motion; контраст; громкость.
- Звук: только после сознательного включения, отключение и управление громкостью; речи персонажей представлены текстом.
- Финал: копирование локального рекламного генома, скачивание JSON, необязательная ссылка на отдельную рекламную платформу, перезапуск и архив.
- Restart: очищает киносеанс текущего режима; настройки просмотра остаются.

## Замена контента

Сцена: `shot(id,image,camera,mood,duration,title,eyebrow,subtitle,voice,choices,hotspots,overlay)`.
Кадры: `assets/keyframes/<image>-desktop.webp` и `...-mobile.webp`.
Добавить узел можно в `story/scenes.mjs`, обновить `docs/STORYBOARD.md`, затем запустить `npm test`. Ошибки отсутствующего перехода и недостижимых сцен ловит `graphIssues`.
