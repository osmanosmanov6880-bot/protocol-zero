# PROTOCOL ZERO — CINEMATIC INTERACTIVE ENGINE v1.0.0

**Статус:** рабочая локальная кинематографическая веб-история. Не является опубликованным коммерческим сервисом.

## Конкретно реализовано

1. Полный сценарий на 15 структурированных сцен: сюжет, заголовки, кадры, движения камеры, настроение, 15 режиссёрских строк раскадровки, реальные ссылки переходов, hotspot-объекты, реплики и визуальные оверлеи.
2. Трёхсценный прототип в том же движке, с двумя исходами выбора.
3. Рабочий state machine: маршруты по явному графу, история решений, назад, архив ранее открытых сцен, сохранение/восстановление состояния через localStorage, пропуск вступления и перезапуск.
4. Редактор единственной мутации HOOK/TONE/CTA с ограничением длины, отказом от простых неподтверждённых численных обещаний и показом изменения родительской/новой версии.
5. Локальная выгрузка рекламного генома в JSON и копирование текста, без ложного утверждения о публикации или продажах.
6. Visual runtime: WebP desktop/mobile, плавное CSS движение камеры, переходы, HUD, процедурный Canvas atmospheric dust, pause on hidden tab, preload максимум двух непосредственно доступных следующих кадров.
7. Звуковое оформление через WebAudio по явному включению пользователя; без внешних сервисов, без загруженных коммерческих треков.
8. RU интерфейс, дополнительный EN/中文, три ручных режима качества + auto, `prefers-reduced-motion`, high contrast, видимый фокус, текстовые реплики.
9. Нормальная модульная версия и два автономных HTML-файла со встроенными сценическими изображениями, а также статический HTTP-сервер Node 22 без npm-зависимостей.
10. Полная документация: концепция, style bible, storyboard 15 сцен, граф, 15 точных shot prompts, asset manifest, audio cues, API взаимодействий, запуск, ограничения качества, QA.

## Проверки

- **19/19 Node автотестов**, включая достижимость всех 15+3 узлов, ветви, истории, мутацию, экспорт, корректную структуру изображений и реальные ответы встроенного HTTP-сервера.
- Реальный локальный сервер: `GET /`, `/prototype/`, `/src/app.mjs`, `/assets/keyframes/city_dawn-desktop.webp`, `/healthz` отдаёт успешные HTTP 200.
- Desktop 1440×900 и mobile 390×844: визуальные сцены без горизонтального overflow в проверенных сценариях.
- Изолированный Chromium browser bridge со встроенными идентичными модулями и теми же WebP: трёхсценный прототип (обе ветки проверены), полный Desktop-маршрут (до финала A и B, создание редакторского текста, модальное окно архива и скачивание JSON).
- Ограничение среды: прямой `page.goto(http://localhost)` и даже произвольные внешние домены блокируются политикой Chromium. Поэтому **не заявляется проверенной** браузерная навигация по реальному опубликованному домену. Для неё потребуется отдельный e2e на своей машине/стейджинге.

## Честные ограничения визуала

Кадры в релизе — композиционные кропы из двух AI-концептов с последующим upscale в WebP 1600×900 и 720×1080, **не настоящие нативные 4K/8K**. Для production premium-качества потребуется перегенерировать 9 чистых ключевых сценических изображений согласно `docs/SHOT_PROMPTS.md`. Движок и интерфейс для замены готов.

## Не сделано

- Воспроизведение синтетической атмосферы не равно профессиональному аудиопроизводству.

## Самопроверка

Распаковать ZIP в новую папку, установить Node.js 22.13+, запустить `npm run check`, затем `START_WINDOWS.cmd` на Windows или `npm start`. Открыть `http://127.0.0.1:8080`, пройти сюжет и скачать JSON. Для автономного просмотра использовать `VIEW_OFFLINE.html`.
